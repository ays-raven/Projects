# Electronics & Robotics Projects

A collection of projects documenting my journey through **electronics, embedded systems, and robotics**.

The repository contains projects built to apply what I learn through **design, programming, simulation, calculations, and practical experimentation**.

## Projects

Each project is organized independently based on what it requires.
Projects may include:

* Circuit design and calculations
* Simulations
* Source code
* Wiring diagrams
* Design explanations
* Photos and videos
* Practical test results

## Purpose

This repository serves as a record of what I build and learn — from individual electronic circuits to complete robotic systems.

The focus is not only on the final result, but also on the **reasoning, experimentation, failures, and improvements** behind each project.

More projects will be added as I continue learning and building.
